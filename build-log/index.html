建站日志

此处记录 ICEBBS 的主要版本、架构变化与重要更新。

小规模文字修改、内容修正等一般不单独记录； 当网站出现具有阶段意义的变化时，则发布新的版本号。

ICEBBS v0.3.0

Board System · 版块系统建立

2026-09-02

本版本在 v0.2.0 静态化重构的基础上， 正式建立 ICEBBS 的版块与文章组织体系。 网站开始从单纯的静态首页， 向具有完整内容分类、文章索引与论坛式浏览逻辑的个人网站发展。

本次更新仍然坚持纯 HTML、CSS 与 JavaScript 的轻量结构， 不重新引入复杂的前端框架。 各版块将作为软件、硬件、体育、游戏、铁路、影像、 音乐、文学与学习等长期内容的独立入口。

主要改动

  • 首页版面索引扩展至 10 个正式版块。
  • 建立“站务公告”版块， 用于网站通知、版本消息与重要说明。
  • 建立“软件开发”版块， 用于程序设计、工具制作与软件项目记录。
  • 建立“硬件开发”版块， 用于电子制作、设备改造与硬件项目记录。
  • 建立“体育随笔”版块， 用于比赛观感、运动见闻与体育评论。
  • 建立“游戏世界”版块， 用于游戏体验、历史回顾与相关内容。
  • 建立“铁路旅行”版块， 用于铁路见闻、线路记录与旅行札记。
  • 建立“光影世界”版块， 用于摄影、电影及影像创作记录。
  • 建立“冰点之声”版块， 用于音乐、声音作品与收听记录。
  • 建立“文学随笔”版块， 用于阅读、写作与文学随想。
  • 建立“学业漫谈”版块， 用于学习方法、课程记录与学术见闻。
  • 为各版块建立独立页面， 首页版块名称由装饰性栏目正式转变为可访问入口。
  • 新增统一文章数据文件 posts.js， 集中保存版块信息与站内文章数据。
  • 新增 forum.js， 实现文章数量自动统计、最新文章识别、 日期排序及版块文章渲染。
  • 首页“文章”与“最新文章”开始由实际文章数据自动生成， 不再需要手工填写数量与最后更新时间。
  • 为版块页面加入初步“发帖”编辑器， 可直接在浏览器中填写标题与正文并生成文章。
  • 当前浏览器发帖功能使用 localStorage 保存数据，仅作为前端功能原型； 内容暂不会写入 GitHub 仓库，也不会在不同设备之间同步。
  • ICEBBS 的模块化内容体系初步形成， 为后续持续加入真实文章、项目、照片、音乐及其他个人内容建立基础。

ICEBBS v0.2.0

Static Rebuild · 静态化重构

2026-09-02

本版本对 ICEBBS 的底层架构进行了第一次重大调整。 网站从最初由 Codex 搭建的现代 Web 工程， 重构为直接由浏览器读取的纯 HTML + CSS 静态网站。

此次重构的主要目的并不是追求更先进的技术， 而是使网站进入一个能够被自己完整理解、 修改和长期维护的阶段。

主要改动

  • 将网站主体重构为纯 HTML + CSS 静态页面。
  • GitHub Pages 改为直接从 main / root 分支目录部署。
  • 移除 vinext、Vite、React、pnpm 等原有构建体系。
  • 移除原 GitHub Actions 自动构建流程。
  • 建立真正可独立访问的 /build-log/ 页面。
  • 保留并迁移 Codex 初版所建立的主要视觉风格。
  • 清理不再使用的工程配置、依赖及开发环境文件。
  • ICEBBS 正式进入自主开发与维护阶段。

ICEBBS v0.1.0

Codex Prototype · 初始原型

2026-09-01

ICEBBS 的第一个可公开访问版本。

网站最初由 Codex 根据 ICEBBS 的定位与视觉设想完成原型搭建， 建立了论坛式首页、主要色彩体系、导航结构与基础页面布局， 并首次部署至 GitHub Pages。

主要内容

  • 建立“冰点论坛 / ICEBBS”的基础视觉体系。
  • 确立论坛式个人网站的整体页面结构。
  • 建立冰点公告、开发与构建、个人项目、 阅读与写作、游戏与数码、生活随笔等初始板块。
  • 使用 React、vinext、Vite 等现代 Web 技术构建第一版工程。
  • 建立 GitHub 仓库并完成首次 GitHub Pages 部署。
  • ICEBBS 正式上线。

版本编号规则

ICEBBS 使用三段式版本号：

v主版本.功能版本.修订版本

  • 主版本： 网站发生根本性的架构或定位变化。
  • 功能版本： 增加新的主要功能、板块或完成阶段性重构。
  • 修订版本： 修复问题、调整样式或进行较小规模更新。

ICEBBS v1.0.0 将保留给网站基本结构、 核心板块与主要功能全部完成的第一个正式版本。
